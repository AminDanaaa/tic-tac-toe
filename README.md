# tic-tac-toe
Summary: Tic Tac Toe game in browser (from The Odin Project)

### More info about this repository:
Using Pure JS (ES6), HTML and CSS to practice some fundamentals and learning how things exactly work in JS.
This project was made during "The Odin Project" course on "Full-Stack JavaScript" and may be improved and used later as a personal project, who knows?

Used IIFEs and prototypes as the course asked, then switched to Class syntax. Was useful to learn how JS classes work compared to Java.
